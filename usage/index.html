    Using the TUI¶

    The MUST TUI launches in a terminal and provides interactive access to telemetry parameters, their metadata, and time-series plots.

    Press F1 at any time for an in-app help screen covering usage and the full list of keyboard shortcuts — the same reference as the Global Key Bindings section below, generated from the app's own bindings so the two can't drift apart.

    Panels¶

    Search Input¶

    The search box at the top filters or navigates the parameter list as you type.

    • Filter mode (default): The list is narrowed down to parameters whose name or description match the search text. By default the search text is treated as a regular expression. Uncheck the Regex checkbox to switch to fuzzy matching instead.
    • Jump mode: The best fuzzy match is highlighted in the alphabetically sorted list, with up to 500 neighbouring parameters shown around it. Toggle jump mode with Ctrl+J.

    The Regex checkbox (top-right of the search bar) switches between regex and fuzzy matching while in filter mode.

    The search checks the MIB name, the description shown in brackets in the list, and the MUST/PCF extended description — each as its own field, so an anchored pattern like ^NC01_FRAME matches the bracketed description directly, not just where it happens to sit inside the full list entry.

    The search runs once you pause typing for a moment, not on every keystroke, and a spinner covers the parameter list while it's running. While a regular expression is incomplete or invalid (e.g. an unclosed parenthesis), the list keeps showing the previous matches.

    Parameter List¶

    The left panel lists all parameters retrieved from the MUST server for the configured data provider. Each entry is shown as:

    MIBNAME [Description]

    To keep the interface responsive, the list shows at most 500 parameters at a time out of however many currently match. When there are more, the last entry reports how many are left out; select it (or press Enter while it's highlighted) to load all of them — this can take a few seconds for a very large, unfiltered list — or refine the search instead to narrow it down.

    Scroll through the list with the arrow keys or the mouse. Press Enter (or click) to select a parameter — this loads its MIB info, server metadata, and time-series data into the other panels. Server data is loaded in the background, so the interface stays responsive. If you select another parameter before the previous one has finished loading, the previous request is cancelled and only the latest selection is loaded. A request is abandoned, and reported in a dialog, when the MUST server sends no data for 30 seconds; slow transfers that keep receiving data are not interrupted.

    Parameter Metadata¶

    The upper-right panel shows live metadata fetched from the MUST server for the selected parameter.

    Field Description
    description Parameter mnemonic from the server
    data-type Data type (e.g. UNSIGNED_SMALL_INT)
    first-sample Timestamp of the earliest available sample
    last-sample Timestamp of the most recent available sample
    subsystem Subsystem (e.g. TM)
    id Internal parameter identifier
    unit Engineering unit
    parameter-type Parameter type
    name MIB name
    provider Data provider name
    plotted-samples Number of data points fetched for the current plot; – while unknown (computed locally, not from MUST)

    Plot Controls¶

    A toolbar between the info panels and the plot area:

    Control Action
    Clear Plot button Remove all plotted traces
    Plot: TUI / Plot: Matplotlib button Toggle between the built-in TUI plot and an external Matplotlib window
    Data Range button Set the time range to the selected parameter's first and last sample, as reported by MUST
    Y Range button Set an explicit Y-axis minimum and maximum, or go back to auto-scaling
    Start → End fields Set the start and end time for data retrieval and the plot x-axis
    Lock checkbox Keep the duration fixed: changing one end moves the other end along

    By default the Y-axis auto-scales to fit whatever is currently plotted. The Y Range button opens a small dialog with Min and Max fields (pre-filled with the currently plotted data's range, or the active locked range if one is set) and three actions: Apply (validates that Min is less than Max), Auto (clears the locked range immediately), and Cancel. Once a range is locked, it stays in effect — across new parameter selections, time range reloads, and clearing the plot — until you choose Auto again, for both the TUI and Matplotlib backends.

    Type a date-time as YYYY-MM-DD HH:MM:SS. Shorter forms are accepted too: YYYY-MM-DD HH:MM (seconds 0) and YYYY-MM-DD (midnight). A field is applied when you press Enter or leave it (e.g. with Tab); typing alone changes nothing. Escape leaves the field, committing a pending valid edit first, the same as Tab.

    Relative forms are also accepted, resolved against the current local time:

    • now, today, yesterday, tomorrow — today/yesterday/tomorrow snap to local midnight; now keeps the current time, to the second.
    • Any of those with a signed offset, e.g. now-6h, tomorrow+1d, yesterday-3h. The offset uses weeks, days, hours, minutes and seconds, and they can be combined: now-1d2h30m.
    • A bare offset such as -2h30m or +1w is relative to now. The sign is required (6h alone is rejected as ambiguous).

    ↑ / ↓ step the date-time component the cursor is on (year, month, day, hour, minute, second) up or down by one, directly in the field's text — without applying it, so pending edits are still only applied on Enter/Tab/Escape. Stepping a relative expression first resolves it to an absolute date-time, then steps it. Stepping the day/month clamps to the last valid day of the resulting month (e.g. 31 Jan + 1 month → 28 Feb); stepping past year 1000 or 9999 does nothing.

    If the text is not a valid date-time, or the start would not be before the end, the field turns red, a notification explains why, and the time range stays as it was. Editing the field removes the red mark.

    When the time range changes, the x-axis moves to the new range and all plotted parameters are fetched again for it. A notification shows when the reload starts and when it is done; parameters without data in the new range are listed there and removed from the plot. Selecting a parameter fetches and plots its data for the current time range.

    Plot¶

    The lower-right area renders a time-series plot of the selected parameter(s). Multiple parameters can be overlaid — each new selection adds a trace without clearing previous ones. The title lists every currently plotted parameter (Parameter: X for one, Parameters: X, Y, … for several), each one colored to match its trace. The Matplotlib backend shows a real legend instead; a legend in the TUI plot can crash the terminal plotting library in some situations, so the title's coloring is used there instead.

    To keep the terminal plot fast, each trace is drawn with at most 1000 points. Long series are reduced by keeping the minimum and maximum of each time bucket, so spikes and dips remain visible. The Matplotlib backend always shows the full-resolution data.

    Fetching a parameter with many samples in the selected time range can take a while — data is retrieved page by page (5000 samples per request, over one reused connection, to avoid one huge request to the MUST server), and all of it is retrieved before anything is drawn. A spinner covers the plot area while a selection or a time range change is being fetched, and the Parameter Metadata panel's plotted-samples field shows the resulting point count once it's done. If a single parameter's data in the selected range is extremely large (over 5,000,000 samples), a notification reports that only the first part of it was loaded.

    Use the Clear Plot button (or press Ctrl+L) to reset the plot.

    The plot marker style can be cycled through four options (Braille, Standard Definition, High Definition, Dot) with F3.

    Global Key Bindings¶

    These bindings are available anywhere in the application. Every one of them is a Ctrl-combo or a function key — none are bare letters, so none are ever swallowed by the search box as typed text, regardless of where focus is:

    Key Action
    F1 Open this help
    Ctrl+Q Quit the application
    Ctrl+L Clear all traces from the plot
    Ctrl+Z Maximize the plot and its controls, hiding everything else; press again to restore
    Ctrl+J Toggle between Filter and Jump search mode
    F2 Toggle plot backend between TUI (built-in) and Matplotlib
    F3 Cycle plot marker style (Braille → SD → HD → Dot)
    F4 Toggle light / dark mode
    F5 Soft-refresh the parameter cache (fetches from server, keeps SQLite cache)
    Ctrl+R Hard-reset the parameter cache (wipes SQLite cache, then re-fetches)

    Only the first four (F1, Ctrl+Q, Ctrl+L, Ctrl+Z) are shown in the footer, to keep it short; the rest still work exactly the same, they're just not advertised there. The full table — generated from the same bindings the app actually uses, so it can't go out of date — is always available by pressing F1.

    The status line above the footer shows the data provider, connection state, the number of parameters currently loaded, and how long ago the parameter cache was last refreshed.

    Startup Screens¶

    Loading Screen¶

    On startup the app shows a loading screen while it:

    1. Authenticates with the MUST server.
    2. Loads MIB parameter info from the bundled pcf.dat.
    3. Fetches the parameter catalog.

    If authentication fails the app offers the choice to Abort or continue in offline mode (no server data, MIB browsing only).

    Main Screen¶

    After loading, the main screen is shown with the parameter list. The parameter catalog is loaded from the local SQLite cache when available. A background refresh from the server runs at startup only when the cache is missing or older than one day; press F5 to refresh it at any time.

    Plot Backends¶

    TUI (default)¶

    The built-in Textual plot renders directly in the terminal. No graphical session is required.

    Matplotlib¶

    Requires a graphical desktop session with a window manager. When enabled, an external Matplotlib window opens alongside the terminal and stays in sync with the time range and parameter selections. Switch back to the TUI backend with F2 or the Plot: TUI button.
